# GameKit

> [!NOTE]
> The project is currently under development.

In many game development teams, developers repeatedly solve the same set of problems when building casual games: designing the project architecture, implementing screen and popup navigation, integrating A/B testing, adding in-game currencies, and other common gameplay mechanics.

**GameKit** is an experimental project that aims to bring together the most common systems used in casual mobile games and provide a convenient starting point for new projects.

By forking this repository, you get a base Unity project that includes:

- [Production mode](Documents/GameKit/Product/production-mode.md) switcher
- [Current Time](Documents/GameKit/Product/current-time.md)
- [UI Regions](Documents/GameKit/Product/ui-regions.md)
- [Pages](Documents/GameKit/Product/pages.md)
- [Popups](Documents/GameKit/Product/popups.md)
- [Debug panel](Documents/GameKit/Product/debug-panel.md)
- [Player State](Documents/GameKit/Product/player-state.md) persistence
- [Currencies](Documents/GameKit/Product/currencies.md)
- [Energy](Documents/GameKit/Product/energy.md) with restoration

The project follows an AI-driven development approach, including Spec-Driven Development, Docs-as-Code, Domain-Driven Design, and Test-Driven Development.

Technical documentation: [Engineering](Documents/GameKit/Engineering/README.md)
