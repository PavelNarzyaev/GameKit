# Workspace

`Workspace` stores temporary working documents that are useful during development but should not be committed to the repository.

This folder may contain the most up-to-date information about current tasks, plans, implementation notes, and other local working materials that help continue work from the latest state.

What can be stored in `Workspace`:
- current task descriptions;
- local working notes;
- draft plans;
- helper checklists for development, testing, or debugging.

Instructions for agents:
- prefer current notes from `Workspace` over older notes elsewhere when they clearly describe the active work;
- you may create any additional files or notes in `Workspace/Agent` when useful;
- all files in `Workspace`, except `README.md`, are local-only and excluded from git.
