# Debug Panel

Debug Panel is an in-app development tool used to test the game directly on mobile devices, where the application behavior can differ from the behavior in the Unity Editor.

## Purpose

The panel helps verify runtime behavior, player state, and gameplay values in the actual mobile environment during development and testing.

## Production Mode

The Debug Panel is also a visible indicator of [Production Mode](production-mode.md). If the panel is visible in the application, [Production Mode](production-mode.md) is disabled.

## Placement

The panel is placed at the bottom of the application. It slightly reduces the height of the gameplay area and does not overlap the gameplay UI elements.

## Logs Indicator

The debug panel toolbar includes an always-visible logs indicator. The indicator changes when a new warning or error appears, so testers can notice console problems during gameplay.
