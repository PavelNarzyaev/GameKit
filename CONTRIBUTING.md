# Contributing

GameKit is intended to remain publishable as a public source repository.

Before adding code, packages, assets, fonts, art, generated SDK files, documentation, or other materials, make sure their license allows redistribution in a public source repository.

Do not add Unity Asset Store assets in raw source form under the standard Asset Store EULA unless there is a separate license or written permission that allows redistribution in this repository.

When adding third-party materials, update [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) with the material name, repository path, source, and license or terms reference.

Do not commit Unity-generated cache/build folders such as `Library`, `Temp`, `Obj`, `Build`, `Builds`, `Logs`, or `UserSettings`.
